# Branthaven IT Help Desk

Free (standard connectors only) help desk on Microsoft 365: SharePoint list, Forms, Planner, Teams, Power Automate and a Power Apps Teams app.

- `generator/gen.py` – builds every flow package; `validate.py` checks them
- `flows/` – importable flow packages (import each with "Import Package (Legacy)")
- `app/` – Power Apps app notes and logo assets
- `docs/` – End-User-Guide.md, IT-Tech-Guide.md

**Keep this repo private.** The flows contain mailbox names and the Forms ID.
